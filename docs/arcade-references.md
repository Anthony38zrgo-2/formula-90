# Referencias arcade

## Hechos verificables

F1 Exhaust Note y F1 Super Lap son títulos arcade de Sega; Final Lap R es un título arcade de Namco. Este proyecto no reutiliza código, arte, audio, marcas, circuitos ni material de ROM.

## Interpretaciones de diseño

Una cámara alta trasera, sprites grandes, lectura limpia de carretera, cambios perceptibles y respuesta inmediata evocan el lenguaje visual y jugable de esas recreativas.

## Decisiones propias

`formula-90s` usa circuito 3D plano, coche Sprite3D original, seis marchas ajustables, agarre lateral simplificado y FOV dependiente de velocidad. No replica contenido de ningún título.
