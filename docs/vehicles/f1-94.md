# F1-94 en La Chutana

La fuente canónica es el paquete desacoplado
`assets-lowpoly-python/vehicles/F1_94_DECOUPLED`. La escena cargada por
`scripts/run_f1-94.ps1` consume su copia runtime en
`game/assets/models/vehicles/f1_94/decoupled`.

El paquete usa metros y la semántica runtime de GEVP: `+Y` arriba, `+X` a la
derecha y frente en `-Z`. La escena no rota ni desplaza el chasis. Los centros
de rueda y datums están definidos en `decoupled/manifest.json`.

El runtime canónico cargado por `scripts/run_f1-94.ps1` cumple el manifiesto
estándar de tres GLB:

- `F1_94_chassis_geometry.glb`
- `F1_94_wheel_front_geometry.glb`
- `F1_94_wheel_rear_geometry.glb`

GEVP conserva cuatro `RayCast3D` independientes. Cada `wheel_node` es el hijo
directo `FrontLeftWheel`, `FrontRightWheel`, `RearLeftWheel` o `RearRightWheel`,
con `Visual` debajo. Las ruedas derechas llevan el yaw de 180 grados aplicado
en un nodo de presentación, con determinante `+1` y sin escala negativa. Las
dos ruedas delanteras comparten un recurso GLB y las dos traseras comparten
otro; sus cuatro instancias y estados físicos siguen siendo independientes.

Para validar la estructura desacoplada y sus referencias:

```powershell
python scripts\validate_f1_94_decoupled.py
```

Para validar importación, cuatro contactos, HUD, velocímetro y minimapa:

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\scripts\run_f1-94.ps1 -Smoke
```
