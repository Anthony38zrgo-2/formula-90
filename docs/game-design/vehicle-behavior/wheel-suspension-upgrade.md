# Wheel / Suspension Mechanical Upgrade

Scope: mechanical interaction only. `powertrain.rs` and `aero.rs` are intentionally unchanged.

## Runtime chain

`Godot transverse tricast -> contact coverage/road target -> tire carcass -> virtual unsprung wheel -> suspension/ARB/bump stop -> dynamic Fz -> transient tire forces -> rigid body`

## Integration contract

- Keep the existing three rays per wheel: `Inner / Center / Outer`, transverse across tire width.
- Keep their maximum reach compatible with `spring_length + unloaded_tire_radius`.
- Continue sending world-space hit `distance`, `point`, `normal`, and `surface` through the existing `TriRaycastSample` FFI path.
- Rust internally substeps the vertical wheel mechanics. Do not add a second Godot spring/damper for the same wheel or the compliance will be double-counted.
- `WheelSuspensionState.total_normal_force` is now the tire/road Fz produced by carcass + unsprung dynamics, not an algebraic spring force.
- `WheelSuspensionState.compression_mm` is the integrated suspension/wheel-center compression, no longer raw ray penetration.
- `dynamic_camber`, `tire_deflection_m`, and `contact_fraction` are forwarded to `TireSystem::set_mechanical_state()` before tire-force evaluation.
- Do not restore the removed GEVP longitudinal pitch-torque aid. Pitch/roll/yaw already emerge from `arm.cross(wheel_force)` at the contact point.
- Self-aligning torque is now generated by pneumatic trail and applied around the effective road normal.

## Implemented mechanical changes

- Correct ARB load-transfer sign: more-compressed wheel gains ARB load, opposite wheel loses the same amount.
- Progressive bump stop starts before full travel; true overtravel remains measurable instead of being clamped away.
- Removed dead dynamic-rebound behavior from `max_spring_length`; it now mirrors usable current spring length for compatibility.
- Added virtual unsprung mass using the existing wheel mass as its basis.
- Added radial tire spring + damping and a progressive hard-carcass region.
- Added tricast contact coverage so 1/2/3-ray contact changes effective carcass support.
- Added filtered tricast road-height excitation to prevent ray membership changes from becoming direct damper impulses.
- Added effective rolling radius from tire deflection.
- Added dynamic contact-patch length from load + carcass deflection.
- Added slip relaxation length for transient lateral/longitudinal force buildup.
- Replaced the old GEVP brush block with a stable combined-slip force model and friction ellipse.
- Added vertical-load sensitivity (`Fz` is intentionally sub-linear in tire grip efficiency).
- Connected tricast-derived camber to tire lateral behavior.
- Projected tire forces and point velocity onto the tricast contact plane.
- Added pneumatic-trail self-aligning torque.
- Wheel rotational inertia now uses a wheel/tire assembly coefficient instead of a solid-cylinder `0.5*m*r^2` assumption.

## Tuning

Mechanical defaults are centralized in `wheel_mechanics.rs` (`WheelMechanicalTuning::for_wheel`). They are derived from the existing vehicle config so old JSON files do not need new keys for this iteration.

Primary knobs for later calibration:

- `unsprung_mass_kg`
- `tire_vertical_stiffness_n_m`
- `tire_vertical_damping_n_s_m`
- `max_tire_deflection_m`
- `rolling_radius_deflection_factor`
- `load_sensitivity_exponent`
- `relaxation_length_m`
- `camber_thrust_gain`
- `pneumatic_trail_m`
- `partial_contact_stiffness_floor`
- `mechanical_substep_s`
- `bump_stop_start_ratio`

Start validation at 120 physics ticks/s or higher. The internal vertical solver currently targets 480 Hz through substeps.

## Validation priorities in Godot

1. Static ride height and per-wheel Fz at rest.
2. Single-wheel curb strike: verify tire deflection occurs before large suspension compression.
3. Wheel drop/recontact: verify no one-frame damper spike.
4. Roll test: outer wheel Fz must increase with ARB stiffness while inner Fz decreases.
5. Bottom-out: `bottom_out_force` must become non-zero before/through travel exhaustion.
6. Partial tricast contact on a curb edge: `contact_fraction` should move 0.25/0.50/0.75/1.00 without multiplying total wheel load by ray count.
7. Increase wheel mass temporarily: wheel-hop/contact tracking should become visibly slower.
8. Straight-line static camber: left/right camber thrust should cancel approximately.
9. Corner entry: aligning torque should build and then fall as front slip saturates.
