F1-94 / Formula-90 / standard import notes
============================================

The repaired source bundle is already in metres with +X right, +Y up and -Z
front. F1_94_GEVP_READY.glb is the complete canonical vehicle and contains the
explicit GEO_ geometry plus DATUM_/JNT_ locators.

The source repair emits F1_94_chassis.glb, F1_94_wheel_front.glb and
F1_94_wheel_rear.glb. The deterministic Formula-90 materializer then creates
the four standard runtime wheel assets:

  f1_94_wheel_fl.glb
  f1_94_wheel_fr.glb
  f1_94_wheel_rl.glb
  f1_94_wheel_rr.glb

Each wheel is recentered at its rotation origin, named GEO_WHEEL_<corner>_* and
stored as an independent GLB. The right-side yaw is baked before export with a
proper determinant +1 rotation. No runtime orientation node or negative scale
is used.

The Godot hierarchy is:

  WheelFrontLeft  -> FrontLeftWheel  -> Visual
  WheelFrontRight -> FrontRightWheel -> Visual
  WheelRearLeft   -> RearLeftWheel   -> Visual
  WheelRearRight  -> RearRightWheel  -> Visual

Run tools/asset_pipeline/generate_f1_94_runtime.py to materialize and validate
the standard runtime directory. Use vehicle_metadata.json as the import
manifest; F1_94_gevp_metadata.json remains the repair provenance report.
