# data — Load-time tuning and configuration

Scope: load-time vehicle profiles, camera rigs, project tuning, input profile, pit-stop rules, race-session presets, track entries, and presentation presets.
Consumers: the physics and audio engines, autoloads, and scenes under `game/scenes/`.
Rules: data-only tuning truth; code defaults never override these files silently. Binary art lives in `game/assets/` and generated pipeline outputs in `game/resources/`; neither belongs here.
Subfolders: each child folder documents itself in its own AGENTS.md.
