# examples — Physics usage examples

Scope: runnable examples driving the dynamics without Godot.
Consumers: physics developers validating setups.
Rules: examples read real vehicle data files; hardcoded setups are forbidden.

The coupled suspension reference, kernel profile, world diagnostic and suspension mass audit are offline evidence producers. Use the current vehicle profile and source-verified physical package. Save outputs under `scratch/`; record configuration, source identity and measured runtime. Numerical or timing reports require explicit acceptance criteria before being described as production validation.
