# psx-art-pluggin — Retro presentation plugin

Scope: the Rust PSX retro-look plugin behind `psx_art_plugin.dll`. The directory keeps its historical spelling; the contract name is PSX art plugin.
Consumers: showcase and vehicle scenes using authentic 1994 presentation.
Rules: look policy comes from `game/data/visuals/`; this crate implements it.
Subfolders: each child folder documents itself in its own AGENTS.md.
