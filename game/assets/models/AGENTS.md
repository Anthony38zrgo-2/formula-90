# models — 3D model programs

Scope: vehicle, driver, and pit-crew model programs, each with authored sources, runtime meshes, and manifests.
Consumers: vehicle and pit-stop scenes plus the Blender, driver, and pit-crew tooling.
Rules: Blender sources stay beside their program folder; exports are regenerated, never hand-patched.
Subfolders: each child folder documents itself in its own AGENTS.md.
