# reference_red_and_gold — Reference paint and sponsor pack

Scope: generated red chassis lacquer, champagne gold wheel finish, and transparent SF-26 sponsor decal atlas.
Consumers: the canonical f1_2030.blend source.
Rules: preserve generated source images and original vehicle geometry. Blender materials provide reflections and roughness. sponsor_decal_layout.json records placements adapted from the lower 2026 car in the supplied reference. Chassis decals use GEO_CHASSIS_DECAL_ names; tire decals use their existing wheel prefix so they follow wheel rotation when exported. Runtime exports are regenerated separately after visual review.
