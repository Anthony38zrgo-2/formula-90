# Vegetation V2 reference bank

Reference images generated from the approved autumn/dry vegetation art direction. These files are source references and are not active runtime cards until the V2 normalization pipeline converts them to the canonical alpha/key contract.

Canonical chroma key for external sources: `#00FFFF` (`[0, 255, 255]`). Legacy magenta `#FF00FF` is not permitted for new V2 sources.
