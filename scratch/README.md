# Scratch

Zona local y descartable para previews, comparaciones A/B, escenas aisladas y
outputs intermedios.

Todo el contenido de este directorio está ignorado por Git excepto este README.

Reglas:

- una preview escribe aquí, nunca directamente en `game/assets` o
  `game/sounds`;
- ningún archivo bajo `scratch/` es contenido aprobado;
- la promoción reconstruye o copia explícitamente desde inputs aprobados;
- el directorio completo, salvo este README, puede eliminarse en cualquier
  momento.
