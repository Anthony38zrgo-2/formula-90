1990 mm width-only revision. Runtime asset id remains `f1_2026_2008`.

## Geometry and integration

The source is the pre-remodel backup at
`D:/Formula90s-backups/f1_2026_2008-jordan-remodel/f1-2026-2008/`.
All 29 original chassis mesh nodes, both original wings, the original halo,
cockpit, sidepods, aero elements and topology are restored. No meshes from the
rejected procedural remodel remain in the exported chassis.

In Blender axes (X lateral, Y forward, Z up), only longitudinal coordinates of
chassis vertices and datums change:

```text
f(y) = y * 3.500 / 3.230                 for abs(y) <= 1.615
f(y) = y + sign(y) * 0.135               outside the axle planes
```

This increases separation between axles while translating the existing nose and
tail overhangs. It does not impose new body contours. X/Z coordinates stay fixed.
Wheel meshes change only laterally: front ×(0.365/0.355), rear ×(0.410/0.400).
Their radius, longitudinal shape and pivot remain unchanged.

Godot wheel centres are `(±0.8175, 0, -1.750)` and `(±0.795, 0, 1.750)`.
Ray origins use tyre width ×0.4: front |X| = 0.6715 / 0.8175 / 0.9635;
rear |X| = 0.631 / 0.795 / 0.959. Existing vertical positions and ray lengths
remain unchanged. The original three chassis colliders are restored; their
longitudinal endpoints receive the same mapping. The two temporary sidepod
colliders from the rejected design are removed.

The physics profile changes only wheelbase and the two tyre widths relative to
the pre-remodel 1990 mm-wide state. Engine/audio, tyre friction coefficients,
spring tuning and aerodynamic coefficients are not recalibrated here.

## Reproduction and review

Requires the above original backup, Blender and Python. These commands overwrite
the current model from that backup; do not substitute the already-modified files
as input:

```powershell
blender --background --factory-startup --python-exit-code 1 --python tools/blender/restore_2026_3500.py
blender --background --factory-startup --python-exit-code 1 --python tools/blender/validate_2026_3500.py
blender --background --factory-startup --python-exit-code 1 --python tools/blender/render_2026_livery.py
```

`validate_2026_3500.py` reimports the actual GLBs. It compares every original
mesh against the prescribed transform in both directions (2 µm tolerance),
checks original triangle counts, wheel datums, dimensions, profile changes,
scene node hierarchy, all 12 rays, and triangle intersections for all 14
suspension-to-hub connections. Reports and hashes are stored alongside the model.

Godot 4.7.1 also imported all three GLBs in a fresh isolated asset-only project:
37 mesh instances including the four wheels, body texture present, width within
10 µm of 2.000 m. Evidence: `reports/2026-3500-jordan/godot_check.log`.
This test does not launch the game or load native vehicle binaries. Driving and
animated suspension behavior have not been tested; game launches must use the
canonical `run_f1_94.ps1` with the project's BUILD/HEAD validation.

The editable `source/f1_2026_2008_source.blend` contains the current assembled
model and packed images, in Blender X-right/Y-forward/Z-up coordinates. It is
ignored by the existing Git policy; distribute it separately when handing off.
Rendered views are in `reports/2026-3500-jordan/` (also ignored).

The rejected model and previous dirty changes were backed up before restoration
to `D:/Formula90s-backups/f1_2026_2008-before-restore-3500/`.
Work stays on `main-clean`, base `0bfeaa9cd67d6744cf987c7689307a78c2306ede`.
