# drivers — Driver character authoring

Scope: reproducible seated driver models derived from the supplied low polygon driver Blender source, plus the legacy Racer generator.
Consumers: vehicle driver visuals under game/scripts/vehicle.
Rules: validate preview and promotion destinations through tools/common/output_policy.py; preserve the pit crew source and outputs. The calibrated torso recline stays fixed when the vehicle seat is reshaped around the driver.

generate_driver_model.py defaults to the low_polygon character model. Uniformly scale the supplied model and adapt the reference skeleton to its anatomy, preserving bone names. Never scale body parts separately, sculpt the source geometry, or substitute the deprecated Racer model in runtime assets. The legacy original option is preview only. Verify all 1171 neutral vertices against the original source within one micrometer and retain its 1445 triangles before export. Exports include DriverOriginalUniformGeometryContract and source provenance. Do not overwrite the reference skeleton during regeneration. Preview destinations contain the exported model, manifest and editable prepared Blender source. Promotion writes the prepared Blender source inside the source folder. validate_driver_geometry_contract.ps1 validates original, prepared source and runtime model hashes and the embedded contract; run_f1_94.ps1 requires this check before launch.

The current low polygon appearance defaults to lewis_hamilton_inspired. Use --driver-appearance original to regenerate the supplied colors. apply_lewis_hamilton_driver_skin.py replaces packed atlases and visor material after preparing the current model, verifies structural equality before and after saving, and rejects the deprecated Racer manifest. Appearance profiles live under game/assets/models/drivers/skins.
