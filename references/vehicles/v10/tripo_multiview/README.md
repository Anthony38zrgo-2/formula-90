# Referencias V10 para Tripo 3D

Conjunto generado para el flujo **Smart Mesh > Multi-view** de Tripo.

## Orden de carga

1. `v10_tripo_front.png` — Front.
2. `v10_tripo_left.png` — Left.
3. `v10_tripo_right.png` — Right.
4. `v10_tripo_rear.png` — Back.

Vista complementaria: `v10_tripo_isometric_front_left.png` — isométrica frontal izquierda elevada para aclarar superficies superiores, cockpit, sidepods y relación entre ambos alerones. Úsala como referencia adicional cuando la interfaz permita más imágenes o para evaluar el modelo generado; las cuatro vistas cardinales siguen siendo el conjunto principal.

## Especificación

- PNG RGB de 24 bits.
- 1254 × 1254 px por imagen.
- Fondo gris claro neutro.
- Encuadre cardinal casi ortográfico.
- Iluminación difusa, sin escenario ni sombras duras.
- Mismo coche blanco V10 y acabado prerenderizado high-color de los 90.

No recortar cada vista de manera diferente antes de subirla. Tripo obtiene mejores restricciones geométricas cuando escala, iluminación y encuadre permanecen consistentes.
