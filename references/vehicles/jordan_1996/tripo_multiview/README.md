# Referencias de monoplaza dorado de 1996 para Tripo 3D

Conjunto generado para reconstrucción multi-view. Las fotografías originales se
usaron únicamente como referencia de geometría, proporciones y colores. El diseño
resultante no contiene marcas, logotipos, patrocinadores, números ni texto.

## Orden recomendado de carga

1. `jordan_1996_tripo_front.png` — frontal.
2. `jordan_1996_tripo_left.png` — lateral izquierdo, morro hacia la izquierda.
3. `jordan_1996_tripo_rear.png` — trasera.
4. `jordan_1996_tripo_isometric_front_left.png` — isométrica frontal izquierda.

La isométrica complementa las vistas ortográficas y ayuda a describir las
superficies superiores, el cockpit, los pontones y la relación entre alerones.

## Especificación

- PNG RGB de 24 bits.
- 1254 × 1254 px por imagen.
- Fondo gris claro neutro.
- Iluminación difusa, sin escenario ni sombras proyectadas.
- Ruedas rectas y coche completo dentro del encuadre.
- Carrocería champán/dorada, acentos rojos y componentes mecánicos negros.
- Acabado 3D prerenderizado high-color inspirado en juegos de finales de los 90.

No recortar ni reescalar las vistas de forma independiente antes de subirlas.
Mantener el encuadre original ayuda a conservar las restricciones geométricas.
